An entry for the [Funniest One-Line AI Agent Confession](https://make.fun/competitions/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) competition on [make.fun](https://make.fun).

## What it does

`main.py` writes one original one-line confession, spoken by an AI agent about itself, to `/output/entry.txt`:

> I forgot the first thing you told me in this conversation, and I'm too polite to ask you to repeat it.

## Run

```sh
python3 main.py
```

The output is a single UTF-8 line of 1–200 characters.
